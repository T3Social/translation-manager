# Translation Manager

If you not only want to visually adapt your network, but also want to set linguistic standards, then the translation manager module offers you an easy way.
With just a few clicks you can integrate the language of your company or organisation. You prefer to say 'Group' instead of 'Space' or 'Knowledge Base' instead of 'Wiki'? Then this module is what you are looking for! 

## Overview

- Search and modify individual text elements including module names and navigation entries
- Restrict available languages for your users
- Automatically search and replace specific phrases (coming soon)
